# Dossier des images de l'interface

Dépose ici le logo de l'Institut Supérieur des Sciences de la Population
(ISSP) sous le nom **`logo_issp.png`** (PNG de préférence, idéalement avec un
fond transparent). Il apparaîtra automatiquement :

- au-dessus du formulaire de connexion (`auth.py`) ;
- comme icône d'onglet du navigateur (`app.py`).

Aucune autre modification de code n'est nécessaire — l'application détecte
le fichier tout seule à chaque démarrage. S'il est absent, l'écran de
connexion reste stylé (couleurs, carte centrée) mais sans logo.
