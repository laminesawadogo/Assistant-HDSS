Table: TBase_vacc

Titre: Table TBase_vacc
Description: Vaccination Table

Variable observeid (table TBase_vacc) : OBSERVATION ID. Type: Identifiant.

Variable individid (table TBase_vacc) : INDIVIDUAL ID. Type: Identifiant.

Variable socialgpid (table TBase_vacc) : HOUSEHOLD ID. Type: Identifiant.
